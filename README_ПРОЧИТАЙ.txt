HEIC → PDF | ТРИ ТОМА ДЕЛА
========================
Программа для Windows 10/11 (64-битная). Фотографии остаются на вашем ПК.

1. РАСПАКУЙТЕ ВЕСЬ ZIP В ОТДЕЛЬНУЮ ПАПКУ
   Не запускайте BAT прямо внутри ZIP: сначала извлеките его содержимое.

2. ЗАПУСТИТЕ START_WINDOWS.bat ДВОЙНЫМ ЩЕЛЧКОМ
   Требуется Python 3.12, 64-битная версия.
   Если Python нет: https://www.python.org/downloads/
   При установке отметьте "Add python.exe to PATH".
   При ПЕРВОМ запуске нужен интернет для установки библиотек.
   Дальше вся обработка фотографий выполняется ЛОКАЛЬНО, без отправки данных.

3. КАК СДЕЛАТЬ PDF
   - Нажмите «Выбрать папку с фотографиями» (все 700 HEIC).
   - По умолчанию порядок: ПО ИМЕНИ ФАЙЛА СНИЗУ ВВЕРХ.
   - Слева фотографии по порядку, справа предпросмотр. По кнопке «Увеличить»
     можно проверить номера листов, видимые на самих снимках.
   - Если нужно, перемещайте снимки кнопками «Вверх» / «Вниз», поворачивайте их.
   - Найдите первую фотографию ВТОРОГО тома и нажмите «Начало ТОМА 2».
   - Найдите первую фотографию ТРЕТЬЕГО тома и нажмите «Начало ТОМА 3».
   - Выберите качество. Для документов рекомендуется «Исходный размер».
   - Нажмите «СОЗДАТЬ 3 PDF», укажите папку сохранения.
   - Получите Том_1.pdf, Том_2.pdf, Том_3.pdf и, по выбору, общий PDF.

4. КАК НЕ ПОТЕРЯТЬ ПОРЯДОК
   «Сохранить проект» создаёт небольшой JSON со списком страниц, поворотами и
   границами томов. Открыть его впоследствии можно кнопкой «Открыть проект».

ВАЖНО
- Названия файлов / даты изменения не гарантируют порядок номеров листов.
  Программа НЕ распознаёт напечатанные на фото номера листов автоматически.
  Перед экспортом проверьте порядок по предпросмотру, особенно в начале
  и в конце каждого тома.
- PDF: одна фотография = одна страница A4; кадр целиком, без обрезки.
- При создании PDF нужны свободное место на диске и оперативная память.
  Общий файл с 700 страницами может получиться очень большим.
  При недостатке памяти можно отключить «Дополнительно общий PDF».
- Исходные HEIC не изменяются.
- Настоящий EXE можно собрать на Windows с помощью BUILD_EXE_WINDOWS.bat.
  Перед этим один раз запустите START_WINDOWS.bat.

ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ
HEIC, HEIF, JPG, JPEG, PNG, WEBP, TIFF, BMP.

Никаких платных приложений для преобразования HEIC не нужно.
